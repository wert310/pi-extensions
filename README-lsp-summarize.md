# LSP Output Summarizer Extension

This pi extension intercepts large LSP (Language Server Protocol) tool outputs and:

1. **Truncates** outputs that exceed configurable limits
2. **Saves** the full output to a temporary file
3. **Summarizes** the truncated output using an AI model
4. **Returns** both the summary and truncated output to the main agent

## Features

- **Automatic truncation**: Outputs exceeding size limits are automatically truncated
- **Full output preservation**: Complete output is saved to a temp file for later access
- **AI-powered summarization**: Truncated outputs are summarized using a configurable model
- **Configurable limits**: Set custom byte/line limits and truncation mode
- **Flexible model selection**: Use the current session model or configure a specific one

## Installation

The extension is already installed in `.pi/extensions/lsp-summarize.ts`. It will be automatically loaded when you run pi in this project directory.

To use it globally, copy it to `~/.pi/agent/extensions/`:

```bash
cp .pi/extensions/lsp-summarize.ts ~/.pi/agent/extensions/
```

## Configuration

### Via settings.json

Create or edit `~/.pi/settings.json`:

```json
{
  "lspSummarize": {
    "model": "ollama/qwen2.5:32b",
    "maxBytes": 51200,
    "maxLines": 2000,
    "truncateMode": "tail"
  }
}
```

### Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `model` | string | "" (use current) | Model to use for summarization. Empty string uses the current session model. |
| `maxBytes` | number | 51200 (50KB) | Maximum bytes before truncation |
| `maxLines` | number | 2000 | Maximum lines before truncation |
| `truncateMode` | "head" \| "tail" | "tail" | Which part to keep: "head" keeps beginning, "tail" keeps end |
| `prompt` | string | (see below) | Custom prompt template for summarization |

### Via Environment Variables

- `LSP_SUMMARIZE_MODEL`: Model to use (e.g., "ollama/qwen2.5:32b")
- `LSP_SUMMARIZE_MAX_BYTES`: Max bytes before truncation
- `LSP_SUMMARIZE_MAX_LINES`: Max lines before truncation
- `LSP_SUMMARIZE_TRUNCATE_MODE`: "head" or "tail"
- `LSP_SUMMARIZE_PROMPT`: Custom prompt template (use `{output}` as placeholder)

### Default Prompt Template

```
Summarize this LSP (Language Server Protocol) output concisely. Focus on:
- Key findings, errors, or warnings
- Important definitions, references, or diagnostics
- Actionable information for the developer

Keep the summary structured and brief (3-10 bullet points if possible).

<LSP_OUTPUT>
{output}
</LSP_OUTPUT>
```

## Commands

This extension does not register any custom commands. Configuration is done via:
- `~/.pi/settings.json` file
- Environment variables

To view current configuration, check `~/.pi/settings.json` or use the environment variables listed above.

## Usage Example

When the LSP tool produces large output:

```
pi> Use lsp action=diagnostics on file LargeFile.lean
```

If the output exceeds the configured limits, you'll see:

```
## LSP Output Summary (generated by ollama/qwen2.5:32b)

- Found 335 type mismatch errors in LargeFile.lean
- All errors follow the same pattern: String used where Nat expected
- Errors occur on lines 3-335+ at column positions 20-22
- This appears to be a test file with intentional type errors

---

[Truncated output showing last 2000 lines...]

[Output truncated: showing 2000 of 3000 lines (50KB of 75KB). 
1000 lines (25KB) omitted. Full output saved to: /tmp/pi-lsp-XXXXXX/output.txt]
```

## How It Works

1. The extension listens for `tool_result` events from the `lsp` tool
2. When an LSP result is received, it checks the output size
3. If the output exceeds configured limits:
   - Truncates the output (keeping head or tail based on configuration)
   - Saves the full output to a temporary file
   - Calls the configured model to summarize the truncated output
   - Returns the summary + truncated output + file path to the main agent
4. If summarization fails, returns just the truncated output with file path

## Dependencies

- pi coding agent with extension support
- Access to an AI model for summarization (optional)
- Node.js filesystem access for temp file creation

## Troubleshooting

### Model not found

If you see "Model not found" in the logs, ensure:
- The model is configured correctly in settings.json
- The model provider is available
- API keys are configured if required

### Summarization failed

If summarization fails, the extension will still return the truncated output. Check:
- Model configuration
- API key availability
- Network connectivity

### Extension not loading

Ensure the extension is in the correct location:
- Project-local: `.pi/extensions/lsp-summarize.ts`
- Global: `~/.pi/agent/extensions/lsp-summarize.ts`

Use `/reload` in pi to reload extensions.
